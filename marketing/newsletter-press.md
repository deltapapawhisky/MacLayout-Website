## Newsletter Submissions

### Console.dev

**Submission URL:** https://console.dev/submit

**Tool name:** MacLayout

**URL:** https://maclayout.com

**One-line description:** A native macOS app that saves and restores window layouts with auto-triggers for display changes and app launches.

**What does it do?**

MacLayout saves your window arrangements as named layouts and restores them with one click, a keyboard shortcut, or automatically. It detects display configuration changes (docking/undocking a laptop) and restores the appropriate layout without any user action. It also supports macOS Spaces, app launch triggers, and per-display awareness.

**How is it different?**

Existing tools like Rectangle and Magnet snap individual windows to grid positions. MacLayout saves and restores your entire workspace state — every window, every app, every Space — at once. The auto-trigger system (restore on display change, restore on app launch) is something no other macOS window manager offers.

**Tech details:** Native Swift/SwiftUI app. Uses macOS Accessibility API for window manipulation. Sparkle for auto-updates. Distributed outside the App Store (Accessibility API is incompatible with sandboxing).

**Pricing:** $19.99 one-time. 14-day free trial.
