## Lemon Squeezy Setup Instructions

### Step 1: Navigate to Discount Codes

1. Log in to your Lemon Squeezy dashboard at [app.lemonsqueezy.com](https://app.lemonsqueezy.com)
2. Go to **Store** > **Discounts** in the left sidebar
3. Click **+ New Discount**

### Step 2: Create Each Code

For each code in the table above, fill in:

- **Name:** A descriptive name (e.g., "Reddit 10% Off", "Press Reviewer Free License")
- **Code:** The exact code from the table (e.g., `REDDIT10`)
- **Discount type:** Percentage
- **Discount amount:** 10 (or 100 for REVIEWER)
- **Apply to:** Select your MacLayout product
- **Usage limits:**
  - `REDDIT10`: No limit (or set a generous limit like 500)
  - `PRODUCTHUNT10`: No limit (or 500)
  - `HACKERNEWS10`: No limit (or 500)
  - `NEWSLETTER10`: No limit (or 500)
  - `REVIEWER`: Limit to 50 uses (review periodically)
- **Expiration:** No expiration for launch codes. Consider adding expiration dates later to create urgency for future campaigns.
- **Is enabled:** Yes

### Step 3: Test Each Code

1. Go to your checkout page: `https://[your-store].lemonsqueezy.com/checkout/buy/[product-id]`
2. Apply each discount code and verify:
   - The discount applies correctly
   - The final price is correct ($17.99 for 10% off $19.99)
   - The code name appears in the checkout summary
3. Do NOT complete the purchase — just verify the discount applies

### Step 4: Verify Attribution Tracking

Each code acts as a channel attribution tag. To track performance:

1. Go to **Store** > **Orders** after launch
2. Filter by discount code to see how many orders came from each channel
3. Track metrics:
   - Orders per code
   - Revenue per channel
   - Conversion rates (if you have click tracking on your site)

## How to Use These Codes in Marketing

### Reddit Posts
Add at the end of your post:
> If you want to try it, here's 10% off: use code **REDDIT10** at checkout. [maclayout.com](https://maclayout.com)

### Product Hunt
Include in your maker's comment or replies:
> As a thank you for the Product Hunt community: use **PRODUCTHUNT10** for 10% off.

### Hacker News
Mention casually in your Show HN comment:
> HN readers can use **HACKERNEWS10** for 10% off if you decide to buy.

### Newsletter / Press
Include in outreach emails:
> I've included a 10% discount code for your readers: **NEWSLETTER10**

### Reviewers
Include in press pitch emails:
> I've attached a promo code for a free license: **REVIEWER** (100% off at maclayout.com)
